한국 카드 혜택 리서치

카드사가 스스로 공개한 기계판독 피드에서 수집한 데이터입니다. 제3자 카드 비교 서비스의 비공개 API 를 사용하지 않습니다.

읽기 전에
  • 금융 조언이 아닙니다. 개인 리서치용 참고 데이터입니다.
  • 카드 혜택은 수시로 변경·단종됩니다. 신청 전 반드시 각 카드의 공식 상품 페이지와 상품설명서를 확인하세요.
  • 피킹률은 약관상 월 한도를 모두 채웠다는 가정의 추정치이며 실제 절감액과 다릅니다. 한도가 확인되지 않은 혜택은 0 원으로 계산해 과소추정될 수 있습니다.
  • 원본 피드에 오탈자·잘린 금액이 있는 경우가 있어, 확실하지 않은 수치는 비워 두었습니다. 빈 값은 "혜택이 없음"이 아니라 "확인하지 못함"을 뜻합니다.
  • 한도가 포인트로만 표기된 혜택(1만 M포인트 등)은 피킹률 계산에서만 1포인트 = 1원으로 가정합니다. 포인트의 실제 가치는 사용처에 따라 다릅니다.
