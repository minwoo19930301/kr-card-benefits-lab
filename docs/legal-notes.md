# 자료 이용과 권리 관계

이 저장소는 공개된 카드 상품 정보를 정리하는 개인 리서치 도구입니다.
카드 발급·추천·세금 납부를 대신 실행하거나 금융·법률 판단을 확정하지 않습니다.
아래 내용은 프로젝트의 자료 취급 방침이며 개별 사이트 이용이나 재배포에 관한 법률 자문은 아닙니다.

## 정확성과 적용 범위

카드 혜택은 변경·축소·단종될 수 있고, 공개 원문이나 자동 추출 결과에도 오류가 있을 수 있습니다.
원문 수집 성공과 모든 조건의 확인은 다릅니다. `source.retrieved_at`, `review_status`, 공식 원문 링크를 함께 확인하세요.

알 수 없는 조건은 미확인으로 남깁니다. 빈 값은 혜택 없음, 세금 실적 제외, 적립 불가라는 뜻이 아닙니다.
기존 자료를 보존한 카드는 해당 자료의 원래 수집일을 유지하며 새 자료로 보증하지 않습니다.
신청이나 납부 전에는 공식 상품설명서·약관·행사 공지에서 본인에게 적용되는 범위를 확인해야 합니다.

피킹률은 알려진 월 한도를 채웠다는 가정의 계산입니다. 실제 지출 배분·제외 조건·연회비까지 반영한 순절감액이 아닙니다.
포인트 환산과 한도 미확인 처리 등 계산 가정은 [방법론](methodology.md)에 있습니다.
기간 행사는 상품의 상시 혜택과 분리하며, 저장된 기간 안에 있더라도 변경·조기 종료 가능성까지 실시간 확인한 것은 아닙니다.

## 코드와 원문 자료의 권리

[MIT 라이선스](../LICENSE)는 이 저장소의 코드에 적용됩니다.
카드사 문구·이미지·상표·원문 자료에 관한 제3자의 권리를 대신 허락하는 라이선스가 아닙니다.

카드사명과 카드 브랜드는 해당 권리자의 표시이며 이 프로젝트와 제휴·후원 관계가 있다는 뜻이 아닙니다.
공개 산출물에는 비교에 필요한 사실·수치·간단한 요약과 공식 출처 링크를 저장합니다.
원문 페이지 전체를 대량 전재하거나 카드 이미지를 재호스팅하는 자료집으로 사용하지 않습니다.

공개 URL에 접근할 수 있다는 사실과 복제·재배포·상업적 이용 권한은 별개입니다.
그런 용도로 확장할 경우 원문 사이트의 이용 조건과 관련 권리를 별도로 확인해야 합니다.

## 공식 출처와 외부 비교 서비스

카드 상품의 근거는 카드사 공식 공개 페이지·피드·상품설명서·행사 공지로 한정합니다.
외부 비교 서비스나 가계부 앱이 구축한 데이터베이스·내부 API·이미지 CDN 자료를 가져와 재배포하지 않습니다.
필드 이름을 바꾸거나 일부 항목을 제거해도 데이터의 원래 출처가 바뀌는 것은 아닙니다.
공식 도메인 검사와 금지 출처 검사는 [`validate.mjs`](../scripts/validate.mjs)에서 수행합니다.

## 수집 수단과 접근 조건

현재 공통 수집기는 Bright Data와 공식 사이트 직접 HTTP 요청을 선택할 수 있습니다.
Bright Data는 전송 서비스이며 카드 정보의 저작자나 공식 출처가 아닙니다.
해당 서비스의 사용 권한·요금·약관과 대상 원문의 접근·재이용 조건은 각각 확인해야 합니다.
도구가 원문을 반환했다고 대상 콘텐츠의 재이용 권한이 자동으로 생기지는 않습니다.

수집 범위는 로그인 없이 공개된 상품 정보입니다. 개인 계정·이용명세·인증 세션 같은 비공개 자료는 수집 대상이 아닙니다.
요청 수와 동시 요청 수를 제한하고, 인증·권한·할당량 오류나 반복 실패를 실행 결과에 남깁니다.
접근 불가·추출 실패를 정상 상품 정보로 꾸미거나 기존 데이터의 날짜만 새로 바꾸지 않습니다.

기존 개별 수집기의 robots 검사와 동작은 해당 구현에 남아 있습니다.
이전 문서의 “명시 Allow가 없으면 모든 수집 금지” 같은 고정 규칙이 현재 공통 전송 방식 전체를 설명하지는 않습니다.
자동 접근 안내와 이용 조건을 용도별로 검토하는 일은 기술적으로 어떤 수단을 쓰는지와 별개입니다.

## 원문 캐시와 자격 증명

원문 HTML은 재검증에 필요한 로컬 캐시로 **저장소 밖**에 보관합니다.
Git 커밋이나 정적 사이트 산출물에 원문 캐시를 포함하지 않습니다.
공개 보고서는 공식 URL·확인 시각·해시·시도 결과 등 추적에 필요한 정보를 남기며 원문 전체를 담지 않습니다.

Bright Data API 키는 실행 환경 또는 지정한 외부 자격 증명 파일에서 읽습니다.
API 키·인증 헤더·쿠키·개인 세션을 코드, 오류 보고서, 데이터, 화면에 노출하지 않습니다.
모의 테스트 결과와 실제 유료 요청 결과를 구분하고, 실제 사용 내역은 실행 보고서의 전송 방식과 요청 수로 확인합니다.

## 정정·삭제 요청

공식 원문과 다른 값이나 권리상 문제가 발견되면 저장소 이슈에 해당 카드·공식 URL·문제 항목을 알려주세요.
키·계정 정보나 개인정보를 이슈에 첨부하지 마세요.
확인 후 정정·삭제하고 관련 출처와 갱신 기록을 함께 관리합니다.

## 개인정보와 화면

상품 수집의 대상은 공개된 상품 정보이며 개인정보가 아닙니다.
대시보드의 검색·필터는 브라우저 안에서 실행되며 별도의 광고·행동 분석 스크립트를 사용하지 않습니다.
공식 링크를 열거나 수집 서비스를 호출할 때의 통신·접속 기록은 해당 사이트와 서비스의 정책을 따릅니다.
